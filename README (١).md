# تطبيق عهدي 90 (Ahdi90)

تطبيق أندرويد للانضباط الذاتي يضم:
- قائمة المهام اليومية مع شريط التقدم الدائري الأخضر والمنبهات الدقيقة.
- حارس وسائل التواصل الاجتماعي (شاشة مساءلة: من أنت؟ ما هدفك؟ هل أنجزت مهمتك؟).
- مساعد الواتساب الذكي للرد التلقائي على الرسائل العادية والتنبيه الفوري للرسائل المهمة باستخدام Gemini API.
- حفظ مشفّر لمفتاح API والبيانات الشخصية باستخدام `EncryptedSharedPreferences`.

## البناء التلقائي لملف APK عبر GitHub Actions
بمجرد رفع ملفات المشروع إلى مستودع GitHub، سيعمل ملف `.github/workflows/build-apk.yml` تلقائياً لبناء التطبيق وتوفير ملف `Ahdi90-APK` جاهزاً للتحميل من تبويب **Actions**.
