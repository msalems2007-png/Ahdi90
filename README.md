# عَهدي 90

تطبيق أندرويد عربي لتحدي 90 يومًا. يبدأ افتراضيًا من اليوم التالي لأول تشغيل، ويعرض علامة يومية، سلسلة التزام، تقويم 90 يومًا، وتذكيرًا صباحيًا.

## بناء APK
1. افتح المجلد في Android Studio.
2. انتظر Gradle Sync.
3. Build > Build APK(s).
4. ستجد ملف debug APK داخل `app/build/outputs/apk/debug/`.

ملاحظة: بيئة المحادثة الحالية لا تحتوي Android SDK/Gradle، لذلك لا أستطيع تنفيذ عملية compile هنا لإرفاق APK ثنائي جاهز. المشروع كامل وقابل للبناء مباشرة في Android Studio.
